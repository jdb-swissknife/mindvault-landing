- The React/Vite app builds at /tools/index.html. Existing /#/<tool> URLs forward to /tools/#/<tool>, retaining query strings and hashes.
- All source booking URLs now point to https://calendar.app.google/ksdfb41yF333wmv76. Built files are generated by npm run build, not hand-edited.
- /privacy/ is a directory alias of the existing public/privacy.html, so GitHub Pages can serve /privacy without SPA fallback.
- The SEO one-pager existed only on gh-pages; its exact existing contents are now preserved in public/resources/seo-aeo-geo-one-pager/index.html.
- Existing audience-intelligence, review intake, and privacy files are byte-identical to gh-pages. demo.html is identical except its requested booking URL replacement.
- Existing jb@trustmvs.com contact addresses are intentionally retained. They are functional identifiers, not founder display names. Opaque base64 image bytes are not rewritten.
- Local .env.local copied from the existing landing checkout is ignored by Git. Never commit environment files or credentials.
